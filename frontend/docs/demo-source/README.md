# Демо-ролик «Авито Обмен»

Отдельный проект: собирает демо-видео из скриншотов рабочего фронта.
Держится вне репозитория кейса намеренно — Remotion тянет рендерер и ffmpeg,
а в командном монорепо это лишний вес.

## Как пересобрать

```bash
pnpm install

# 1. поднять фронт в соседней папке
pnpm --dir ../avito-chain dev

# 2. снять экраны (скрипт сам ходит по роутам, переключает персон и жмёт «Не подходит»)
node shoot.mjs http://localhost:5173

# 3. посмотреть или отрендерить
pnpm studio                      # предпросмотр с таймлайном
pnpm render                      # out/avito-obmen.mp4
```

Кадр вертикальный (1080×1920): ролик смотрят с телефона, экраны продукта тоже вертикальные.

## Что где

- `src/scenes.ts` — сценарий: какой экран показываем, с каким заголовком и сколько секунд.
  Правится в первую очередь, когда меняется продукт.
- `src/Intro.tsx` — титры: три человека по кругу. Объясняют идею до первого скриншота.
- `src/Scene.tsx` — экран в рамке телефона + подпись.
- `shoot.mjs` — съёмка скриншотов со свежего фронта.

После изменений в UI достаточно заново прогнать `shoot.mjs` и `pnpm render` —
скриншоты перезапишутся, сценарий править не нужно, пока не поменялся состав экранов.
