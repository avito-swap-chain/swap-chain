# Frontend

Зона React/TypeScript frontend. На этапе общего bootstrap здесь намеренно нет
вложенной структуры и сгенерированного Vite-проекта, чтобы не конфликтовать с
наработками frontend-команды.

После переноса приложения frontend должен использовать контракт из
`../api/openapi.yaml`; сетевые вызовы не следует смешивать с визуальными
компонентами. Подробные правила находятся в корневом `AGENTS.md`.
