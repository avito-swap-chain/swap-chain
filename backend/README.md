# Backend

Зона Go backend. На этапе общего bootstrap здесь намеренно нет вложенной
структуры и формального кода: команда backend сможет перенести свои наработки без
конфликтов с заранее созданными пустыми пакетами.

При инициализации ожидаются `go.mod`, точка входа HTTP API и `GET /health` в
соответствии с `../api/openapi.yaml`. Детальные границы слоёв и бизнес-инварианты
описаны в корневом `AGENTS.md`.
